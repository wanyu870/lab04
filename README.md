# 梁天驰 · 个人作品集

一个基于原生 HTML、CSS、JavaScript 构建的个人作品集网站，展示个人信息、技能方向与项目作品。

## 功能

- **顶部吸顶导航**：桌面导航 + 移动端抽屉菜单，滚动时背景模糊
- **区块高亮**：导航与右侧进度轴跟随滚动自动高亮当前区块
- **个人介绍 / 技能 / 作品 / 关于 / 联系** 五大区块
- **项目作品**：由数据文件动态渲染，包含图片、标签、链接
- **滚动出现动效**：元素进入视口时渐显
- **深浅色主题切换**：一键切换，通过 `localStorage` 记住用户选择
- **响应式布局**：兼容桌面端、平板与手机端

## 技术栈

- 原生 HTML5、CSS3、JavaScript（ES5 风格）
- 不使用前端框架，不依赖第三方 UI 库
- 图标使用内联 SVG

## 项目结构

```
.
├── index.html              # 页面主体结构
├── css/
│   ├── base.css            # 变量 / 重置 / 排版尺度（含深色主题变量）
│   ├── layout.css          # 导航 / Hero / 技能 / 关于 / 联系 / 进度轴
│   ├── components.css      # 项目条目 / 标签 / 主题按钮 / 动效
│   └── responsive.css      # 平板 / 手机断点
├── js/
│   ├── theme.js            # 深浅色主题切换
│   ├── main.js             # 导航高亮 / 滚动出现 / 移动菜单
│   ├── render.js           # 项目渲染
│   └── projects-data.js    # 项目数据
└── assets/
    └── images/             # 图片资源
```

## 运行方式

无需构建，直接通过本地静态服务器打开，例如：

```bash
# 在项目根目录执行，然后访问 http://localhost:8000
python -m http.server 8000
```

也可以直接用浏览器打开 `index.html` 文件。
